# Changelog

## 1.2.2 — 2026-11-01
- Author set to Gnaciux.

## 1.2.1 — 2026-11-01
- New logo. The toolbar icon uses a version without lettering so it reads at 48 px.

## 1.2.0 — 2026-11-01
- Renamed to **Export EPUB to PDF**.
- New compact dialog in the style of Supernote's own (Chauvet) dialogs.
- English by default, Spanish when the system language is Spanish.
- The PDF is written to a private temporary file and copied to `EXPORT` only when complete.
- Removed the PNG/diagnostic export and the alternative annotation-layer mode.

## 1.1.0 — 2026-11-01
- Fixed "0 annotated pages": the annotation index was read before the read permission was granted.
- When no annotation index is available, pages with ink are found automatically.
- New greyscale PDF writer: faster and about three times smaller.
- Cancel button.

## 1.0.0 — 2026-11-01
- First version (Spanish only, full-screen UI).
